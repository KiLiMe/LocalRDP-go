# 代码导读

LocalRDP 的代码地图：目录职责、包边界、进程链路、改动前必读的坑。路径一律相对仓库根。
用法见 [使用说明.md](使用说明.md)，工程约定见 [../AGENTS.md](../AGENTS.md)。

## 目录

```text
LocalRDP-go/
├── main.go                  入口，一行 os.Exit(rdp.Run(os.Args))
├── build.ps1                构建：版本对账 + -X 注入
├── res_test.go              ico 与 .syso 的一致性守护
├── rsrc_windows_amd64.syso  exe 图标与版本信息，go build 自动链入
├── internal/
│   ├── rdp/                 命令行 + RDP 宿主（package rdp，最大的一个包）
│   ├── app/                 窗口逻辑：动作、子进程、状态
│   ├── ui/                  只画 State：窗口、表单、会话页、主题、图标
│   ├── store/               设置、DPAPI 密码（叶子包）
│   ├── i18n/                英文文案 → 中文映射
│   ├── win32/               app 与 rdp 共用的 Win32 小工具
│   └── mcp/                 MCP 协议层（JSON-RPC 2.0 over stdio）
├── tools/                   resync.ps1（资源）、genicon（画图标）、barpreview（预览顶栏）
├── winres/                  version.txt + localrdp.ico（版本与图标源）
├── docs/                    使用说明 / 手动授予特权 / 故障代码 / 代码导读（本文件）
└── .github/workflows/ci.yml windows-latest：vet / gofmt / test / build
```

## 一览

| 包 | 定位 | 关键文件 |
| --- | --- | --- |
| `internal/rdp` | 命令行与 RDP 宿主：解析参数、建无边框宿主窗口、嵌 `mstscax.dll`、把进程塞进子会话 | `run.go` `host.go` `ax.go` `rdp.go` `session_launch.go` |
| `internal/app` | 窗口侧逻辑：按钮动作、子进程管理、状态刷新、读 `command.txt` | `actions.go` `child.go` `status.go` `commands.go` |
| `internal/ui` | 只读 `State` 画界面，点击只调 `Actions`，不碰进程 | `window.go` `form.go` `session.go` `dialogs.go` `theme.go` |
| `internal/store` | 设置与 DPAPI 加密密码，不依赖其它内部包 | `config.go` `secret_windows.go` |
| `internal/i18n` | 英文文案到中文的映射，缺条目回落英文 | `i18n.go` |
| `internal/fault` | 已知故障的代码与一句话：`E###` + `docs/故障代码.md` 的锚点，不依赖其它内部包 | `fault.go` |
| `internal/win32` | 两边都要用的小工具，只写一份 | `win32.go` `single.go` |
| `internal/mcp` | MCP 协议层：`initialize` / `tools/*` / `resources/*`，只用标准库 | `mcp.go` |

## 边界与链路

依赖方向自上而下，`app → ui → store → i18n`；`rdp` 不 import `app`/`ui`。

进程间靠命令行衔接：GUI 按钮 `exec` 本 exe 的 `desktop`/`start`/`status`/`stop`，所以
`internal/app` 不 import `rdp`/根包；唯一向上一跳是 `internal/rdp/gui_shim.go` 调 `app.Run` 开窗口。

RDP 控件怎么嵌进去、登录后各阶段的时序，见 [使用说明.md 第 6 节](使用说明.md)。

## 改动前必读

- `IPersistStreamInit::InitNew()` 在 `SetClientSite` 之前调用会让 mstscax 崩溃 → 本实现默认跳过。
- 控件 QI `IOleInPlaceSiteEx`；不提供它控件走 windowless 模式，永远白屏；提供了才建真窗口。
- `DoVerb` 成功后必须 `SetObjectRects`，否则控件窗口高为 0。
- `WM_CLOSE` 里先 `Disconnect()` 再退出；直接在事件回调里 `DestroyWindow` 会卡死。
- `VARIANT` 在 x64 是 24 字节；`DISPPARAMS.CArgs` 是 `int32`；参数数组要**逆序**填。
- Go 回调进 COM 的线程必须 `runtime.LockOSThread()` 且跑自己的消息循环。
- 新增一个已知故障时要改两处：`internal/fault/fault.go` 里加常量与那一句话，
  `docs/故障代码.md` 里写判据与处理（`fault_test.go` 会核对每个代码都在文档里出现过）。
  程序里只显示代码与一句话，不要往界面上塞长解释。

## 阅读顺序

1. `main.go` → `internal/rdp/run.go`（命令怎么分）→ `host.go`（窗口与消息循环）→ `ax.go` + `dispatch.go`（COM 容器）
2. `internal/rdp/rdp.go`（属性配置）→ `env.go` + `session_launch.go`（子会话与进程）
3. `internal/app`（窗口逻辑）→ `internal/ui`（绘制）→ `internal/store`（设置与密码）
4. 专项：`bar.go` / `overlay.go`（顶栏与浮条）、`mcp.go` + `mcp_tools.go`（AI 接口）

## 构建与资源

```pwsh
pwsh .\build.ps1                 # 版本对账 + -X 注入，产物 build\bin\Release\localrdp.exe
pwsh .\build.ps1 -Clean -Test    # 先清 build、先跑 go vet 与 go test
pwsh .\tools\resync.ps1          # 重生成 winres\localrdp.ico 与 rsrc_windows_amd64.syso
```

- 版本号只认 `winres/version.txt`；`build.ps1` 会读出 `.syso` 里的 file-version 跟它对账，对不上拒绝编译。
- `rsrc_windows_amd64.syso` 是 exe 图标的唯一来源（`internal/rdp/misc.go` 的 `loadAppIcon` 按 ID 1 取），
  `res_test.go` 在 ico 与 syso 脱节时失败。
- CI：`.github/workflows/ci.yml` 在 `windows-latest` 上跑 `go vet ./...` / `gofmt -l .` / `go test ./...` / `go build`，
  push 与 PR 都触发。
